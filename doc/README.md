## 이 문서들의 사용법

**처음 읽을 때**는 순서대로 개념만 훑는다. 명령어를 외우려 하지 말 것.

**실습할 때**는 각 문서의 "직접 해보기" 절을 따라 친다. 출력이 문서와 다르면 그 차이가 배울 지점이다.

**면접 준비할 때**는 각 문서 끝의 "예상 질문과 답변 포인트"만 훑는다. 평가 루브릭의 항목 3(핵심 기술 원리)과 항목 4(심층 인터뷰)에 대응한다.

## 안전 수칙

실습 중 아래 명령은 되돌릴 수 없으니 주의한다.

| 명령 | 위험 |
| :--- | :--- |
| `rm -rf` | 확인 없이 통째로 삭제. 경로를 두 번 확인하고 실행 |
| `docker compose down -v` | 볼륨까지 삭제되어 데이터가 사라진다 |
| `docker system prune -a` | 사용하지 않는 이미지·컨테이너·네트워크 전부 삭제 |
| `git push --force` | 원격의 커밋 이력을 덮어쓴다 |

실습은 홈 디렉토리 아래 임시 폴더(예: `~/Desktop/practice`)에서 하고, 끝나면 정리하는 습관을 들이면 좋다.
